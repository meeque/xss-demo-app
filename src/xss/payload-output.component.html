Note:
Under the hood, the XSS Demo App reads the innerHTML property of the DOM tree. The web browser then serializes the DOM tree and returns the resulting HTML source code.
However, web browsers have some leeway when serializing a DOM tree. The serialized representation may not be fully accurate, because not all DOM trees can be serialized to HTML. Also, the web browser may use a more compact representation than the original HTML source code (if any) that actually generated the DOM tree. E.g., the web browser may represent some characters verbatim, even where the original HTML source code used a character entity.
