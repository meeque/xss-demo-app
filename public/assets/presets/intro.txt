Welcome to the XSS Demo App!

Enter your XSS Attack Payload into this Payload Input field!
Or, select one of the Payload Presets from the above menu.

Then, choose a Payload Output that processes your Payload Input.
Payload Outputs are predefined snippets of example web application code.
Some Payload Outputs defend against XSS attacks successfully, others are vulnerable to XSS attacks.
Find out what XSS Attack Payload can exploit a specific Payload Output!

Once you've found a suitable XSS Attack Payload, you can run arbitrary JavaScript code.
For your convenience, the XSS Demo App provides a global JavaScript function named xss().
Invoke xss() and you will see a prominent alert message!
